# Treasure Coast Home Health Services Prototype

A premium, responsive homepage concept for Treasure Coast Home Health Services.

## Current scope

- Custom temporary brand system and favicon
- Responsive desktop, tablet, and mobile homepage
- Service overview and care philosophy sections
- Interactive mobile menu and FAQ accordion
- Click-to-call and request-care calls to action
- Conceptual Treasure Coast service-area presentation

This is a private prototype. Business details, services, coverage, contact information, licensing language, and final brand assets must be confirmed before a public launch.

## Local development

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.
